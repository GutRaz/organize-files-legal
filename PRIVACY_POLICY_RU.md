## Резюме

Organize Files обрабатывает файлы **локально на устройстве**. Содержимое файлов **не загружается на собственные серверы издателя** для обычных операций по организации или восстановлению. Приложение **записывает локальные файлы** на устройстве (снимки сеанса, состояние возобновления, дополнительные журналы), как описано ниже.

## Данные обрабатываются локально

| Данные | Где хранится | Цель |

| Состояние для продолжения упорядочивания + необязательный журнал перемещений | `_OrganizeMediaLogs` в папке вывода или папка сеанса | Пропуск уже выполненных перемещений, данные восстановления с закодированными путями |
| Необязательный файл хода выполнения, JSON | `_OrganizeMediaLogs` в папке вывода | Счётчики хода выполнения для других программ |
| Состояние пробного периода и лицензии | Папка профиля приложения | Применение пробного периода или покупки в магазине |
| Состояние проверки обновлений | Папка профиля приложения | Ограничение частоты необязательной проверки версии |
| Android: копии папок, выбранных через системный выбор SAF | Папка сеанса в хранилище приложения | Копирование деревьев папок `content://`, чтобы движок мог их прочитать |
| Необязательный SMTP-пароль для email-уведомлений | Хранится на устройстве в настройках сеанса в зашифрованном виде (AES-GCM с файлом ключа для профиля). При обновлении, если поле присутствует, старый SMTP-пароль без AES-GCM один раз перезаписывается в AES-GCM. Файл ключа AES-GCM остается в папке профиля приложения и доступен для чтения учетной записи пользователя OS; он защищает от случайного чтения JSON настроек, но не является аппаратным хранилищем. | Только если включены email-уведомления и введены учетные данные SMTP |

## Чего издатель не получает по умолчанию

- Содержимое файлов из прогонов организации/восстановления.  
- Контакты, местоположение, микрофон или камера (не используется)  
- Аналитические или рекламные данные (такой SDK в приложение не входит)  
- Пароли SMTP, сохранённые локально (они остаются на вашем устройстве, если вы не отправляете почту через свой сервер SMTP)
