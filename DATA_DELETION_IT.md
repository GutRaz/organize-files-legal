# Cancellazione dei dati — Organize Files

**Organize Files** elabora i tuoi file **localmente sul tuo dispositivo**.
L'editore **non** gestisce un sistema di account e **non** memorizza i tuoi file
sui propri server durante le normali operazioni di organizzazione o riparazione.
Poiché non esiste un account lato server, la maggior parte dei tuoi dati non
lascia mai il dispositivo e ne mantieni il pieno controllo.

Questa pagina spiega come eliminare i dati che l'applicazione conserva sul
dispositivo e i dati limitati che l'editore può conservare.

## Dati memorizzati sul tuo dispositivo

L'applicazione conserva dati di lavoro locali come istantanee di sessione, stato
di ripresa, log facoltativi, stato di prova o di licenza e — solo se attivi le
notifiche via e-mail — una password SMTP crittografata. Puoi rimuoverli in
qualsiasi momento:

1. **Cancella dati app** — apri l'applicazione e usa **Cancella dati app**. Questo
   rimuove sessioni, log e bozze di automazione. Può conservare lo stato locale
   della licenza e un identificatore di installazione usato per i
   controlli di licenza facoltativi; la conferma nell'app spiega esattamente cosa
   viene conservato.
2. **Disinstalla l'applicazione** — la rimozione dell'app elimina la sua memoria
   privata su dispositivi mobili. Su desktop puoi anche eliminare manualmente la
   cartella del profilo:
   - Windows: `%LocalAppData%\OrganizeFilesCrossPlatform\`
   - Linux / macOS: la cartella del profilo dell'app nella tua directory utente
3. **Elimina le cartelle di output** — tutti i file organizzati o riparati che hai
   creato rimangono finché non li elimini tu.

## Dati che l'editore può conservare

L'editore conserva solo i dati che invii attivamente, come:

- Corrispondenza via **e-mail di assistenza**, se contatti l'assistenza
- **Registrazioni del server di licenze**, solo se è configurato un server di
  licenze per la tua build

Per richiedere la cancellazione di questi dati, scrivi a
**razvan.gutulov@outlook.com** indicando:

- L'indirizzo e-mail con cui hai contattato l'assistenza e/o
- Il riferimento della licenza o dell'ordine, se presente

L'editore si impegna a rispondere entro **30 giorni** da una richiesta verificata.
Alcune registrazioni possono essere conservate quando la legge lo richiede (ad
esempio documenti fiscali e contabili). Consulta l'
[Informativa sulla privacy](./PRIVACY_POLICY_IT.md) per i dettagli completi sulla
conservazione.

## Acquisti negli store

Gli acquisti e la fatturazione sono gestiti dallo store in cui hai acquistato
(Microsoft Store, Google Play o Apple App Store). Per gestire o eliminare i dati
di acquisto conservati dallo store, usa le impostazioni dell'account di quello
store.
