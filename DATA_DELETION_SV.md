# Radering av data — Organize Files

**Organize Files** behandlar dina filer **lokalt på din enhet**. Utgivaren driver
**inget** kontosystem och lagrar **inte** dina filer på egna servrar vid vanliga
organiserings- eller reparationsåtgärder. Eftersom det inte finns något konto på
serversidan lämnar de flesta av dina data aldrig din enhet, och du behåller full
kontroll över dem.

Den här sidan förklarar hur du raderar de data som appen sparar på din enhet,
samt de begränsade data som utgivaren kan lagra.

## Data som lagras på din enhet

Appen sparar lokala arbetsdata som sessionsögonblicksbilder, återupptagningsstatus,
valfria loggar, prov-/licensstatus och – endast om du aktiverar e-postaviseringar
– ett krypterat SMTP-lösenord. Du kan ta bort dem när som helst:

1. **Rensa appdata** — öppna appen och använd **Rensa appdata**. Detta tar bort
   sessioner, loggar och automatiseringsutkast. Det kan behålla lokal licensstatus
   och en anonym installationsidentifierare som används för valfria
   licenskontroller; bekräftelsen i appen förklarar exakt vad som behålls.
2. **Avinstallera appen** — att ta bort appen raderar dess privata lagring på
   mobilen. På skrivbordet kan du även ta bort profilmappen manuellt:
   - Windows: `%LocalAppData%\OrganizeFilesCrossPlatform\`
   - Linux / macOS: appens profilmapp i din hemkatalog
3. **Ta bort utdatamappar** — alla organiserade eller reparerade filer som du har
   skapat finns kvar tills du tar bort dem själv.

## Data som utgivaren kan lagra

Utgivaren lagrar endast data som du aktivt skickar, till exempel:

- **Support-e-post**korrespondens, om du kontaktar supporten
- **Licensserverposter**, endast om en licensserver är konfigurerad för din build

För att begära radering av dessa data, mejla **razvan.gutulov@outlook.com** med:

- E-postadressen du använde för att kontakta supporten, och/eller
- Din licens- eller orderreferens, om sådan finns

Utgivaren strävar efter att svara inom **30 dagar** efter en verifierad begäran.
Vissa poster kan behållas när lagen kräver det (till exempel skatte- och
bokföringsunderlag). Se [Integritetspolicyn](./PRIVACY_POLICY_SV.md) för
fullständiga uppgifter om lagring.

## Köp i butiker

Köp och fakturering hanteras av butiken där du köpte (Microsoft Store, Google Play
eller Apple App Store). För att hantera eller radera köpdata som butiken lagrar,
använd kontoinställningarna i den butiken.
