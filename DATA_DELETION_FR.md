# Suppression des données — Organize Files

**Organize Files** traite vos fichiers **localement sur votre appareil**.
L'éditeur n'exploite **aucun** système de comptes et ne stocke **pas** vos
fichiers sur ses propres serveurs lors des opérations normales d'organisation ou
de réparation. Comme il n'existe aucun compte côté serveur, la plupart de vos
données ne quittent jamais votre appareil et vous en gardez le plein contrôle.

Cette page explique comment supprimer les données que l'application conserve sur
votre appareil, ainsi que les données limitées que l'éditeur peut détenir.

## Données stockées sur votre appareil

L'application conserve des données de travail locales telles que des instantanés
de session, l'état de reprise, des journaux facultatifs, l'état d'essai ou de
licence et — uniquement si vous activez les notifications par e-mail — un mot de
passe SMTP chiffré. Vous pouvez les supprimer à tout moment :

1. **Effacer les données de l'application** — ouvrez l'application et utilisez
   **Effacer les données de l'application**. Cela supprime les sessions, les
   journaux et les brouillons d'automatisation. L'état local de la licence et un
   identifiant d'installation utilisé pour les vérifications de licence
   facultatives peuvent être conservés ; la confirmation dans l'application
   explique exactement ce qui est conservé.
2. **Désinstaller l'application** — la suppression de l'application efface son
   stockage privé sur mobile. Sur ordinateur, vous pouvez aussi supprimer
   manuellement le dossier de profil :
   - Windows : `%LocalAppData%\OrganizeFilesCrossPlatform\`
   - Linux / macOS : le dossier de profil de l'application dans votre répertoire personnel
3. **Supprimer les dossiers de sortie** — tous les fichiers organisés ou réparés
   que vous avez créés restent jusqu'à ce que vous les supprimiez vous-même.

## Données que l'éditeur peut détenir

L'éditeur ne conserve que les données que vous envoyez activement, telles que :

- La correspondance par **e-mail d'assistance**, si vous contactez l'assistance
- Les **enregistrements du serveur de licences**, uniquement si un serveur de
  licences est configuré pour votre build

Pour demander la suppression de ces données, écrivez à
**razvan.gutulov@outlook.com** en indiquant :

- L'adresse e-mail que vous avez utilisée pour contacter l'assistance, et/ou
- Votre référence de licence ou de commande, le cas échéant

L'éditeur s'efforce de répondre dans un délai de **30 jours** après une demande
vérifiée. Certains enregistrements peuvent être conservés lorsque la loi l'exige
(par exemple, les documents fiscaux et comptables). Consultez la
[Politique de confidentialité](./PRIVACY_POLICY_FR.md) pour les détails complets
sur la conservation.

## Achats dans les stores

Les achats et la facturation sont gérés par le store où vous avez effectué
l'achat (Microsoft Store, Google Play ou Apple App Store). Pour gérer ou
supprimer les données d'achat détenues par le store, utilisez les paramètres de
compte de ce store.
