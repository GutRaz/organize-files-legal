# Organize Files — Legal & Support

Public legal and support documents for the **Organize Files** application (Windows, Linux, macOS, Android, iOS).

These documents exist so the app stores (Microsoft Store, Google Play, Apple App Store) and users have a stable, public link to the policies. The application source code is maintained separately. English is the authoritative version; localized files note this and defer to English in case of any conflict.
